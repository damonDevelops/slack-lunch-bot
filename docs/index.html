Lunchbot

Set your Slack status to what you're eating,
with the perfect emoji. Automatically.

How it works

/lunch a spicy burrito 45m
Sets 🌯 Eating: Spicy burrito for 45 minutes
/lunch leftover pasta
Sets 🍝 Eating: Leftover pasta for your workspace default
/lunch clear  ·  /lunch done
Clears your status immediately
/lunch config
Shows your workspace's current default duration
/lunch config 45m
Sets the workspace default to 45 minutes (admins only)
/lunch config reset
Resets to the system default (admins only)
